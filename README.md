# hermes-agent-demo (Python)

Skeleton demo to trigger casual chat via mention or /chat alias.

Usage:
1. Copy .env.example to .env and fill values (DISCORD_TOKEN, OPENAI_API_KEY, CLIENT_ID, GUILD_ID)
2. python3 -m venv venv && source venv/bin/activate
3. pip install -r requirements.txt
4. python src/bot.py

NOTE: This project does NOT contain any real secrets.
